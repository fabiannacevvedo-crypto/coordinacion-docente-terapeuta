# Coordinación Docente-Terapeuta

Aplicación web para facilitar la coordinación e interacion y creacion de informacion entre docentes, terapeutas y familias ,
en instituciones de niveles iniciales , Optimizado la comunicación, el seguimiento de casos y la gestión institucional de manera interactiva y profesiona segun tu rol de registro y nesecidades .

---

##  Funcionalidades actuales
- Gestión de usuarios.
- Registro y seguimiento de reportes.
- Interfaz web adaptable.
- Arquitectura modular 

---

##  Tecnologías utilizadas
- **Frontend**: HTML, CSS, JavaScript,boostrap
- **Backend**: Node.js + Express.  
- **Base de datos**: MySQL (WAMP) + Sequelize ORM.  
- **Gestión de proyecto**: Jira (SCRUM).  
- **Control de versiones**: Git + GitHub.
